# مصادر مُرشدي الرسمية: تحقق 10 أيلول 2026

الملفان الأساسيان مكتملان: `official-admission-cutoffs-2021-2025.json` فيه 607 صفوف عبر 23 خيار جامعة/حرم؛ `official-program-catalog-2026-2027.json` فيه 607 صفوف عبر 21 صفحة. في الحالتين عدد 607 هو عروض تخصصات في جامعات وحرم مختلفة، وليس 607 أسماء تخصص فريدة على مستوى الأردن.

## عقد الاستيراد

- مفتاح البرنامج الرسمي في كتالوج البرامج: `universityCode` + `programCode`، وكلاهما string. أضف فصلًا واضحًا بينهما عند توليد ID.
- ملف الحدود: `universityCode` + `programAr` + `certificateType`، و`yearValues` يخزن الأعوام 2021–2025. يجب ربط الأسماء بإزالة التشكيل والتطويل وتوحيد المسافات، مع رفض الربط الغامض.
- سنة كتالوج الرسوم: `2026/2027`. سنة الحد التنافسي الأحدث: `2025` (العام الجامعي 2025/2026). لا تكتب 2026 على قيم 2025.
- القيمة `eligibilityMinimumPercent` شرط أهلية، وتختلف عن معدل القبول التنافسي؛ نطاق الاستخراج مرشح `علمي` فقط، الرمز 2. الصفحة الرسمية تتضمن أيضًا فروع 2026 الجديدة، لكن لم يُستكمل استخراج أهلية كل فرع.
- الحقول غير المنشورة null. الرمز `-` في المصدر لا يساوي صفرًا.
- ملف الكتالوج لا ينشر `creditHours`. لا تستنتج ساعات الدرجة من رسوم فصل القبول. رسوم المعيشة والدخل والعمل ليست ضمن المصدر.
- وحدة رسوم الكتالوج مؤكدة في شرح الموقع الرسمي https://www.admhec.gov.jo/AboutPage.aspx حيث يصف قسم تخصصات الجامعات بأنه يعرض رسوم الساعات. لذلك يمكن ربط رسم العادي بحقل `creditFee`، دون استنتاج عدد ساعات الدرجة.
- بيانات التوجيهي 2026 وأعداد الدارسين 2025/2026 موجودة في `official-source-manifest.json` مع المصدر والنطاق.

## محول الحدود التنافسية

المصدر: https://www.admhec.gov.jo/LeastAverages.aspx

1. GET ثم اقرأ hidden input fields الموجودة فعلًا؛ احتفظ بالكوكيز في الجلسة.
2. استخرج خيارات select ذي ID `ctl00_MainContentPlaceHolder_ddlUniversity`؛ 0 ليس جامعة.
3. أرسل POST قراءة لكل رمز جامعة مع hidden fields وحقول النموذج:

```json
{
  "ctl00$MainContentPlaceHolder$ddlCertType": "1",
  "ctl00$MainContentPlaceHolder$ddlUniversity": "100",
  "ctl00$MainContentPlaceHolder$btnSearch": "عرض الحدود الدنيا"
}
```

الرمز 1 يعني ثانوية أردنية. أول صف في الجدول هو أسماء الأعمدة: `التخصص`, `2021`, `2022`, `2023`, `2024`, `2025`. اقرأ السنوات ديناميكيًا؛ لا تثبت أحدث سنة في parser. يلي ذلك صف لكل برنامج مع 5 حدود. تحقّق أن الحد إما رقم بين 0 و100 أو علامة عدم توفر. لا تعِد عرض snapshot أقدم على أنه refresh ناجح إن فشل المصدر.

## محول الكتالوج والرسوم

المصدر: https://www.admhec.gov.jo/Majors.aspx

GET، hidden fields، كوكيز كما سبق. POST قراءة:

```json
{
  "ctl00$MainContentPlaceHolder$ddlUniversity": "0",
  "ctl00$MainContentPlaceHolder$ddlBranch": "2",
  "ctl00$MainContentPlaceHolder$ddlSex": "0",
  "ctl00$MainContentPlaceHolder$ddlFacGroup": "-1",
  "ctl00$MainContentPlaceHolder$btnSearch": "🔍 عرض النتائج"
}
```

حافظ على `ctl00$MainContentPlaceHolder$hfAdvFilter=0` كما يرد في hidden fields. البيانات موجودة في `tr.data-row`، سبع خلايا بالترتيب: الجامعة، البرنامج، شرط الأهلية، رسم العادي، رسم التجسير، الموازي الأردني، الموازي غير الأردني. خلية البرنامج تحتوي زر + يُحذف نصه عند استخراج الاسم. كود البرنامج والجامعة في `onclick="toggleDetail(this,'detail_20_100')"`؛ هنا البرنامج 20 والجامعة 100.

الصفحة مرقمة، 30 برنامجًا في كل صفحة، 21 صفحة عند التحقق. اقرأ نص `class="page-info"`: `الصفحة 1 من 21`. للصفحة التالية، حدّث hidden fields من **الاستجابة الأخيرة**، واحذف btnSearch ثم POST مع:

```json
{
  "ctl00$MainContentPlaceHolder$btnNext": "التالي "
}
```

حافظ على قيم بقية الفلاتر. توقف فقط بعد بلوغ الصفحة الأخيرة والتحقق من عدم تكرار رقم الصفحة؛ احمِ المحول بسقف عدد صفحات وزمن وحجم استجابة. حلقة جامعات مستقلة ليست ضرورية لهذا المصدر.

## حالة المنشورات الأخرى

- توجيهي 2026: مؤتمر وزارة التربية في 10 آب، نشر بترا الرسمي في 22:42؛ 196,050 مسجلًا، 178,296 حاضرًا، 116,366 ناجحًا، نسبة 65.3%. التقرير يتحدث عن أول دفعة للنظام الجديد وأول دفعة للمسار المهني التقني.
- دارسو التعليم العالي: الصورة الرسمية `infograf2.png` تغطي مطلع 2025/2026؛ 480,009 إجماليًا، 395,529 بكالوريوس. البيانات ليست خريجين ولا مستخدمي مُرشدي.
- خريجو الجامعات: استكمل المراجع التحقق من نص PDF وصورته؛ الإجمالي 74,718 لجميع الدرجات والجنسيات، منهم 56,781 بكالوريوس، وتغطية الخلاصة 2022/2023. أُضيف الرقمان إلى لقطة التطبيق مع السنة الصحيحة. راجع `graduates-and-fee-verification.md` لدليل المراجع.
- `checkedAt` تاريخ فحص المصدر، و`publishedAt` تاريخ النشر إن ثبت، و`academicYear` سنة البيانات؛ لا يُستبدل أحدها بالآخر.

## نتائج التنفيذ داخل السورس

السورس النشط هو مشروع `mizan` المجاور لمجلد التسليم. يعرّف `src/data/publicData.ts` العقد الموحد، و`src/data/PublicDataContext.tsx` يتيح `usePublicData()`، و`src/components/DataStatus.tsx` يبيّن مصدر الرقم وفترته وحالة آخر تحقق.

- `GET /api/public-data` يعيد آخر نسخة موثقة.
- `GET /api/public-data?refresh=1` يعيد قراءة DOS والتوجيهي وكتالوج القبول والحدود التنافسية.
- أضيف middleware إلى Vite في التطوير والمعاينة. لا يدّعي التطبيق تشغيل التحديث داخل APK دون خادم API.
- أثناء التحقق الفعلي نجحت المصادر الأربعة خلال قرابة 10 ثوانٍ، وبقيت بيانات الإنفوغراف والخريجين بحالة نسخة محفوظة لأن مصادرها صور وPDF لا تُحلل آليًا في هذه المرحلة.
- تحفظ `server/cache/public-data.json` آخر البيانات السليمة، وعند الفشل لا يتغير تاريخ التحقق السابق ولا سنة البيانات. كذلك تدمج مصادر اللقطة الجديدة عند وجود كاش أقدم، وترفض الرجوع إلى فترة مصدر أقدم.
- الاختبارات: `npm test`، 15 اختبارًا ناجحًا؛ `npm run lint` و`npm run build` ناجحان. تحقق HTTP الفعلي من الجذر أكد المصادر الأربعة وعددي 607 و2363.
- فحص مستقل لفلاتر الجامعة أكد أن كتالوج 2026/2027 لا يعرض علم الحاسوب في اليرموك وآل البيت، مع وجود حدود تاريخية ورسوم جامعية منشورة للتخصص؛ لا نضيفه إلى الكتالوج الحالي بغير دليل طرحه.
