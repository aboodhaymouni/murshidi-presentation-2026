1. نظرة عامّة على المنصّة

مُرشِدي منصّة وطنيّة على الأندرويد تساعد طلبة الثانويّة العامّة وأولياء الأمور على اختيار التخصّص الجامعي الأمثل بناءً على بيانات رسميّة من وزارة التعليم العالي ودائرة الإحصاءات العامّة. المنصّة مبنيّة بمعمارية حديثة تجمع بين سرعة التطوير (React) وتجربة المستخدم الأصليّة (Capacitor → Android Native).

الميزات الرئيسيّة

  • 13 شاشة كاملة مغطّية لرحلة قرار الطالب من البداية حتى التسجيل
  • حاسبة عائد التعليم بمنطق رياضي على عشر سنوات
  • مرصد سوق العمل الأردني مع بيانات شهريّة محدّثة
  • اختبار الميول الأكاديميّة (RIASEC المُكيَّف للسياق العربي) — 12 سؤالاً
  • محاكاة المسار المهني بثلاثة سيناريوهات لكلّ تخصّص
  • استشارة ذكيّة مدرّبة على بيانات أردنيّة + 600+ تجربة خرّيج
  • قاعدة بيانات للمنح الدراسيّة الأردنيّة الفعليّة
  • دعم كامل ثنائي اللغة (عربي / إنجليزي) مع تحويل اتّجاه ديناميكي
  • يعمل بالكامل دون اتّصال إنترنت بعد التثبيت الأوّل

الإحصاءات السريعة

10 جامعات أردنيّة

طبقات النظام

1. طبقة العرض (Presentation Layer)

13 شاشة React مكتوبة بـ TypeScript، كلّ منها مكوّن مستقلّ يستهلك:

  • useNavigate / useLocation من React Router للتنقّل
  • useLang من LangContext للترجمات والاتّجاه
  • useKeyboardOpen hook مخصّص لرصد الكيبورد
  • useState / useMemo لإدارة الحالة المحلّيّة

2. طبقة المنطق (Logic Layer)

المنطق الحسابي مدمج داخل المكوّنات (Co-located) عبر useMemo:

  • منطق ROI في ROICalculator.tsx
  • منطق RIASEC في Personality.tsx
  • منطق المحاكاة في Simulate.tsx
  • منطق المطابقة في Chat.tsx

3. طبقة البيانات (Data Layer)

قاعدة بيانات ثابتة TypeScript في src/data/majors.ts:

  • 12 تخصّص (interface Major) مع 16 حقلاً لكلّ تخصّص
  • 10 جامعات أردنيّة مع نوعها وموقعها
  • اتّجاهات سوق العمل (المهن الصاعدة والمتراجعة)
  • إحصاءات وطنيّة (بطالة، عدد الطلبة، إلخ)

7 · i18n Implementation

7. دعم اللغتين (i18n)

المعمارية

منظومة i18n مخصّصة (custom-built) مكوّنة من 3 ملفّات:

  • src/i18n/translations.ts — قاموس بـ 150+ مفتاح ترجمة
  • src/i18n/LangContext.tsx — React Context Provider
  • استخدام مباشر عبر useLang() hook في كلّ مكوّن

كيف يعمل التبديل

1. المستخدم يضغط زرّ AR/EN في صفحة Profile
2. setLang('en') → React Context يُحدّث الحالة
3. useEffect في LangProvider:
   • document.documentElement.lang = 'en'
   • document.documentElement.dir = 'ltr'
   • localStorage.setItem('murshidi.lang', 'en')
4. كلّ المكوّنات تُعيد العرض تلقائيّاً
5. النصوص تتحوّل + الاتّجاه ينقلب RTL→LTR
6. الأيقونات الاتّجاهيّة (chevrons) تتعدّل

المثال البرمجي

// في أيّ مكوّن:
import { useLang } from '../i18n/LangContext';

function MyComponent() {
  const { t, lang, dir, toggleLang } = useLang();

  return (
    <div>
      <h1>{t('app.name')}</h1>
      <p>{lang === 'ar' ? 'عربي' : 'English'}</p>
      <button onClick={toggleLang}>Switch</button>
    </div>
  );
}

9 · ROI Calculator Logic

9. منطق حاسبة عائد التعليم

المعادلة الرياضيّة

employmentProb = 1 − (unemploymentRate / 100)

5yIncome  = ((firstSalary + fiveYearSalary) / 2) × 12 × 5
10yIncome = ((fiveYearSalary + tenYearSalary) / 2) × 12 × 5

totalIncome = (5yIncome + 10yIncome) × employmentProb

yearlyTuition = (gpa >= acceptance) ? govTuition : privateTuition
transport     = (city == 'Amman') ? 800 : 2000
totalCost     = yearlyTuition × duration + (transport + 1500) × duration

netROI         = totalIncome − totalCost
annualReturn   = (totalIncome / totalCost)^(1/10) − 1
paybackPeriod  = totalCost / (firstSalary × 12 × employmentProb)

التطبيق البرمجي

const results = useMemo(() => {
  if (step !== 2) return [];
  return selectedMajors.map((id) => {
    const m = majorsData.find(x => x.id === id)!;
    const yearlyTuition = gpa >= m.averageAcceptance
      ? m.yearlyTuitionGov
      : m.yearlyTuitionPrivate;
    const transport = isAmman ? 800 : 2000;
    const totalCost = yearlyTuition * m.duration
                    + (transport + 1500) * m.duration;
    const employmentProb = 1 - m.unemploymentRate / 100;
    const tenYearIncome =
      (((m.firstSalary + m.fiveYearSalary) / 2) * 12 * 5 +
       ((m.fiveYearSalary + m.tenYearSalary) / 2) * 12 * 5)
      * employmentProb;
    return {
      major: m,
      totalCost,
      netROI: tenYearIncome - totalCost,
      annualReturn: (Math.pow(tenYearIncome / totalCost, 1/10) - 1) * 100,
      paybackYears: totalCost / (m.firstSalary * 12 * employmentProb),
      acceptable: gpa >= m.averageAcceptance,
    };
  }).sort((a, b) => b.netROI - a.netROI);
}, [step, selectedMajors, gpa, city]);

10. عمليّة البناء (Build Pipeline)

2. vite build          ← bundling إلى dist/

4. gradlew assembleRelease ← APK موقّع
5. apksigner verify    ← التحقّق من التوقيع

    }
  }
}

إصدار نسخة جديدة من APK

1. حدّث الإصدار:
   • package.json: "version": "1.1.0"
   • android/app/build.gradle:
     versionCode 2
     versionName "1.1.0"

2. ابنِ:
   $ npm run build
   $ npx cap sync android
   $ cd android && ./gradlew assembleRelease

3. حقّق:
   $ apksigner verify app-release.apk

4. وزّع:
   • Google Play (مع keystore الأصلي)
   • أو نشر مباشر للمستخدمين

التحديث على متجر Google Play

  • مهمّ: استخدم نفس mizan-release.keystore دائماً
  • استخدم نفس applicationId = jo.mizan.app
  • زِد versionCode بـ 1 لكلّ نسخة
  • غيّر versionName حسب نظام Semantic Versioning
